# problem-to-ready

- To turn an initiative into ready-to-implement work, use the `problem-to-ready` skill.
- To add or refresh a domain persona, use the `create-persona` skill.
- Cite only IDs from `knowledge/company.md`, `personas/*.md` and `initiatives/<INIT>/`. Anything else
  is an assumption or a question.
- Never skip a human gate and never mark anything approved.
- After editing checks, run `python -m pytest -q`.
