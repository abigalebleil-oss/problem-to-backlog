# S-MW-3 · QC and result-release regulations summary

Type: standard summary. Written from public sources for the sandbox.

- CLIA (42 CFR 493.1256) sets minimum control procedures, frequency and review for patient testing.
- The CAP checklist adds QC review and corrective action documentation requirements.
- ISO 15189 requires accredited labs to design QC, review it and record corrective action.
- QC rules and limits are lab policy set by the lab director, not software defaults.
