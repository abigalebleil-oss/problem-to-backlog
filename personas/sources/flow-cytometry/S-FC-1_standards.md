# S-FC-1 · Flow cytometry standards and regulatory summary

Type: standard summary. Written from public sources for the sandbox.

- FCS 3.1 (ISAC) defines the data file format. Keywords starting with "$" are reserved by the standard;
  vendor keywords must not use that prefix.
- Most research customers run research-use-only (RUO) workflows. Clinical assays may follow IVD
  (FDA) or CE-IVDR pathways.
- GxP customers expect 21 CFR Part 11 features: audit trail, electronic signatures, user management.
