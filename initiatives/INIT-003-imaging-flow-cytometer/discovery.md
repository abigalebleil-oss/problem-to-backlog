# Discovery output: INIT-003 — Imaging capabilities on a flow cytometer

Started from a one-sentence PO brief with no interviews yet. Worked example of the "start a new
initiative" path: everything below the problem statement is either stated by the PO or listed as
not yet known.

## Problem statement
"I want to write requirements for a flow cytometer that has imaging capabilities."

## Findings
- F-01: The product owner wants requirements for a flow cytometer workflow that includes imaging capabilities [source: 00_po_brief.md]

## Not yet known
- Which users need images, and for which decisions (doublet exclusion, morphology, localization)
- Whether this is a new instrument or a module for an existing one, and its camera and optics
- How images are stored and linked to events, and the expected data volume per run
- The acquisition rate users expect with imaging on
- Which existing panels, templates and analysis tools must keep working unchanged
