## 4. Planning terms
4.1 A milestone is a slice of an initiative committed for a specific release window. Each
milestone delivers user-visible value on its own.
4.2 A customer value delivery (CVD) is a unit of work one team can finish within a sprint that
a named user would notice. It is written as a user need with Given / when / then acceptance criteria.
4.3 A requirement is one testable "shall" statement about the system, derived from a discovery
finding or design element, and verifiable by test, inspection, analysis or demonstration.

## 6. Definition of ready
6.1 A CVD is ready when it traces to a requirement, has testable acceptance criteria, has no
open blocking question, and every assumption it depends on is confirmed.
6.2 A requirement is ready when it has a verification method and cites its source finding or design element.
